Setup shipping

  1. Go to your Yourstore Dashboard and Go to Settings → Shipping Methods
  2. Setup International/Domestic shipping (based on Yourstore plan).
  3. Input your shipping Carrier Name, Tracking Link, Delivery Time and Shipping Charge.
  4. You can also set free shipping above a certain value by enabling the Free Shipping checkbox and input the order value above which the free shipping to be provided under Order Above text box.
  5. If you have a Delhivery, Shiprocket, BlueDart, DHL account you can configure the same by inputting the details requested under Shipping Integration.
