Steps using CSV/XLSX files to import products

In order to upload your products to your online store using Yourstore account, you can use a CSV/XLSX file. For the purpose of this documentation, we will use CSV in all other instances. Both CSV & XLSX are similar and work the same way. With CSV files, you can import multiple products at once. This is useful when importing products from another platform or uploading a large number of products at once.

Download the sample Product Upload file

An example product CSV file is provided below.

    • Products without Variants

      • If your products do not have any variants, such as colour or size, use this template to upload them.

        • Download CSV/XLSX

    • Products with Variants

      • Use this template for uploading products that have variants, such as colours, sizes, etc.

        • Download CSV/XLSX

Formatting the Product Upload file

As shown in the Supported Fields table below & the sample CSV file downloaded, you need to place the column headers on the first line of your product upload file to ensure it functions correctly. The values in these fields are case sensitive and please use as given in the sample file.

Data Dependencies

It is possible to bulk upload data directly, but some options must already be set up in Yourstore's backend before you can add them. In the Yourstore backend, create catalogs, tags, footnotes, tax and taxonomy options before you can upload them to the Product Upload file.CSV (See the Supported Fields table below and the Support Documents available at https://yourstore.io/login/support/products)

Some columns depend on other columns for their data.

Example: In order to update the data in a column related to variants, such as Variant Name and Variant Value, it is necessary to include variant_1_name and variant_1_value as well.

Before you remove or exclude any other columns, verify that the data in those other columns depends on the data in the columns you want to remove or exclude. If you import your product CSV file without the mandatory or dependent columns, your product data will be uploaded with errors or missing information.

Supported Fields in the CSV/XLSX table for products without variants

• Required field are to be filled

• Optional fields can be left blank if you do not have a purpose to use them

Fields/Columns Description
Catalogs
Required

This column should contain the name of the product's catalog/category. The name in this column should match the name created under the catalog in Yourstore Backend. You can tag a product to multiple catalogs.

Be sure to add the necessary catalogs to yourstore backend (Products → Catalog & Products ) before adding them to the CSV file.
Name
Required

This field must contain the name of your product. No special characters are allowed except the hyphen (-).

Example: Red Party Wear Striped Shirt
Unit
Required

Pcs - For all single-unit products or ready- made products

Mts - For custom-length fabrics & items

Kgs - For grocery items, vegetables, etc. that you want customers to select the quantity.

Example: Put Pcs in the Units column if you are selling a readymade shirt
Brand
Optional

It is optional to enter the brand name of the product. You can leave it blank if you are selling your own branded products.

Example: Adidas
taxonomy
Optional

This helps with getting your product listed on Google merchant center and Facebook catalog. The name present in this column should match exactly the name created under the product taxonomy.

Be sure to add the necessary taxonomy data for your products under Products → Product Extras → Product Taxonomy before adding to the CSV file file.
Description
Recommend

A well-written description of your product will increase sales.

Example: This red micro ditsy printed opaque casual shirt features a spread collar, button placket, one patch pocket, long regular sleeves, and a curved hem
Discount
Recommend

Enter Yes if your product has a discount, and No if it does not have a discount
hsn_code
Optional

The HSN code is a 6-digit uniform code that classifies over 5000 products and is accepted worldwide for cross-border shipping. The HSN code stands for "Harmonized System of Nomenclature".
search_keywords
Optional

Enter relevant and possible search keywords separated by commas (,) for the product to help improve its discovery when a user searches for it on the website.

Example: Product Name “Red Party Wear Striped Shirt” Possible search Keywords “Party Wear Shirt, Striped Shirt, Red Shirt, Striped Shirt, Red Party Wear Shirt”
featured_product
Required

Enter Yes if you want to feature this product on the homepage's featured product segment, and No if you don't.
allow_cod
Required

If you want to allow COD for a product, enter Yes. If you don't want COD, enter No.
product_image_1
Required

Upload all the images required for this CSV file under Products → Product Extras → Image Gallery.

Click on the “+ Folder” button on the top right, name the folder and you can select and add up to 50 images at a time, each image should not exceed 3MB, Click on upload. If you want to add more images to the same folder click on “view” to open the folder and click on “+ Images” button inside the folder to add more images to the same folder and repeat the same process for adding additional images. Once you are done adding the required images for this CSV file. Click on the “Export” button to get the data. The exported file will have the image URL’s Copy-Paste the URLs of the image in the product_image_1 column.

Example: uploads/5d0ca4c89f21de03xxx3232/produc ts/cloths/IMG92932A.jpg
product_image_2
Optional

If your product has more than 1 image, enter the other image URLs in the respective columns product_image_2, product_image_3, product_image_4, etc.. You can add up to 10 images per product. To add more images you can add additional column and name the column product_images_5, product_images_6, etc..

Example: Product_image_2 column uploads/5d0ca4c89f21de03xxx3232/ products/cloths/IMG92932B.jpg

Product_image_3 column uploads/5d0ca4c89f21de03xxx3232/ products/cloths/IMG92932C.jpg
sku
Required

In this field, enter the SKU number for each product. SKU values must be unique for each product.
selling_price
Required

Enter the selling price (MRP) of the product in this column.

Example: 1500
discounted_price
Required

Input the discounted price of the product in this field. If there is no discount provided, enter the selling price of the product again in this field.

Example: Selling Price - 1500 If Discount is there - 1200 If No Discount - 1500
stock
Required

Enter the amount of inventory or stock available for the product.

Example: 10
shipping_weight
Required

Enter the exact weight of the product, including packaging.

Example: 500 grams = 0.5, 250 grams = 0.25, 50 grams = 0.05
tax_percentage
Optional

The TAX percentage should be entered if you are collecting TAX on the orders. You must first create the TAX percentages required under Settings →Tax Rates. Only the percentages created under TAX Rates can be inputted in this column.

Example: If you have set up 12% TAX in Tax Rates input 12 in this column
add_ons
Optional

If you have addons for your product created. Include the addons name over here. For products with multiple addons input the options separated by commas (,)

Make sure all the necessary addons are created before adding the addon name to the CSV file Products → Product Extras → Addons

Example: Shirt Customisation, Suite Customisation
addon_mandatory
Optional

If the addons for the product are mandatory, enter Yes, if they are not mandatory and optional, enter No.
size_chart
Optional

Enter the name of the size chart created over here if your products have one.

Make sure the necessary size charts are created before adding them to the CSV file Products → Product Extras → Size Chart

Example: Shirt
image_tags
Optional

You can add tags to your product images here.

Make sure the necessary image tags are created before adding them to the CSV file Products → Product Extras → Image Tags

Example: Trending, Bestseller
tag_1_name
Optional

Tags are filters on the website that allow customers to easily locate products. Enter the name of the tag created in this column of the CSV file.

Make sure the necessary tags are created before adding them to the CSV file Products → Product Extras → Product Tags

Example: Colour
tag_1_value
Optional

Tag values relevant to tag_1_name are listed here. There can be multiple tag values associated with tag_1_name.

To add values to a tag created, click on View button next to the created tag under Products → Product Extras → Product Tags and add the options/values to it

Example: Red, Greeen
tag_2_name, tag_3_name
Optional

For products with only one tag, leave tag_2_name and tag_3_name cells blank. If there are more tags, create extra columns tag_4_name and tag_5_name.
tag_2_value, tag_3_value
Optional

As with tag_1_value, you can create extra columns tag_4_value, tag_5_value, etc. if additional tags are needed. If there is only one tag per product, leave tags_2_value and tag_3_value blank.
footnote_1_name
Optional

The footnotes are additional short descriptions that can be added to the products so that the customer can easily see what they are buying.

Footnotes can be created under Products → Product Extras → Footnote

Example: Sleeve Length
footnote_1_value
Optional

Footnote values relevant to footnote_1_name are listed here. There can be only one footnote value associated with footnote_1_name.

To add values to a footnote created, click on the View button next to the created footnote under Products → Product Extras → Footnote and add the options/values to it.

Example: Full Sleeve
footnote_2_name, footnote_3_name
Optional

For products with only one footnote, leave footnote_2_name and footnote_3_name cells blank. If there are more tags, create extra columns footnote_4_name and footnote_5_name.
footnote_2_value, footnote_3_value
Optional

As with footnote_1_value, you can create extra columns footnote_4_value, footnote_5_value, etc. if additional tags are needed. If there is only one tag per product, leave footnote_2_value and footnote_3_value blank.
