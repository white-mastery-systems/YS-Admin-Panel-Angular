Website Header

A header is important to let visitors know what they're looking for and where to find it. You should make sure that the header is easy to understand so people can easily find their way around the store.

How to Edit Website Header?

  1. Go to your Yourstore Dashboard and Go to Website → Header Menu

Adding a New Menu Item

  1. Click "Add New Menu"
  2. Input a name for your menu.
  3. Use rank to set the position of the menu.
  4. Clicking on "Enable Link", will give you four choices for linking the menu with.

    • Link to Catalog

      • Choose the catalog you would like to link to from the dropdown.

        If you don't see a catalog, create a new catalog by going to Products → Catalog & Products

    • Link to Product

      • Choose the product you would like to link to from the dropdown.

        • If you don't see a product, create a new product by going to Products → All Products

    • Link to Internal Link

      • Enter the portion of URL of any internal pages created using extra pages or any other pages in the website excluding the part already displayed.

        • You can create a new page by going to Website → Pages → Extra Pages

    • Link to External Link

      • Enter the URL of the page to be redirected to on clicking the menu.

        • Your link must start with an http:// or https://

    • Click "Add" to save changes.

Adding a new section, categories & sub-categories in menu item

  1. Click on View and then select “Add Section”, to add an additional level to the menu structure.
  2. On the section created click on View and then select “Add Category”, to add a second level to the menu structure.
  3. On the category created click on View and then select “Add Sub-Category”, to add a third level to the menu structure.
  4. To add more menu items you can refer “Adding a New Menu Item” section above if you need help on adding multiple menu items.

Editing an Existing Menu Item

  1. Click "Edit" on the menu item.
  2. Make changes as per your needs, refer "Adding a New Menu Item" section if you need help on editing the menu items.
  3. Click "Update" to save changes.

Re-ordering Menu Items

  1. Click "Edit" button next to the menu.
  2. Use numbers in Rank to change the position of the menu.
  3. Click "Update" to save changes.
