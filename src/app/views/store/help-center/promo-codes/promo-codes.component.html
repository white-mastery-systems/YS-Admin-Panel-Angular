Create a Promotional/Offer Code

  1. Go to your Yourstore Dashboard and Go to Marketing Tools → Offers
  2. Click "Create New Offer" on the top right corner.
  3. Type the Promo Code you want your customers to use to get discounts in the Discount Code field. For example:
    • OFF40 - to offer 40% Off
    • New10 - to offer 10% off during New Year
    • FLAT100 - to offer flat ₹100 off
  4. Select Type of the Offer based on weather you want to offer a percentage discount or a flat discount.
  5. Enter the discount value of the coupon code
    1. In case of percentage discount, For 40% discount enter 40
    2. If you want to limit your customers to a maximum amount of discount, enter the amount in Enbale Discount Upto checkbox and enter the amount.

      For example, if you want your customers to get a maximum discount of ₹500 on a Promo code 50OFF that offers 50% discount, enter 500 in Discount Upto field.

    3. In case of flat discount, for ₹100 discunt, enter 100
  6. For the offer to work, you can set the requirement as minimum purchase amount or minimum quantity of items or you can set both. Entering 0 allows user to apply the discount on purchase amount without any minimum requirements.
  7. If you want your promo code to work on a minimum order purchase amount, enter the amount in Minimum Purchase Amount textbox.

    For example, if you want your customers to use FLAT500 on minimum order value of 5000. Enter 5000 in the minimum order textbox.

  8. If you want your promo code to work on a minimum quantity of items , enter the quantity in Minimum quantity of items textbox.

    For example, if you want your customers to use FLAT500 on minimum order quantiy of 5 items on checkout. Enter 5 in the Minimum quantity of items textbox.

  9. If you do not want to set any minimum order conditions, leave the value in the textbox as 0.
  10. Limit to one use per customer helps you to limit the number of times a user can use a promo code, enabling this option asks the user login to make a purchase instead of doing a guest checkout.
  11. Limit to number of times can be used helps you to limit the number of times the coupon can be redemed or used overall.
  12. Set a start date and time for the promo code, optionally you can set end date as well.
  13. Click "Add".

Editing a Promo Code

  1. Go to your Yourstore Dashboard and Go to Marketing Tools → Offers
  2. Click the view button to make changes to the offer code.
  3. Follow the steps in Create a Promotional/Offer Code to edit your offer code.
  4. Click "Update".

Deactivating a Promo Code

  1. Go to your Yourstore Dashboard and Go to Marketing Tools → Offers
  2. Click the view button to disable the offer code that you want to deactivate.
  3. Use the toggle to “Enable/Disable” an offer code.
  4. Click "Update".
