Store Settings

Opening Hours

Set up operating hours for your business if you would like to provide store pickup for your customers in addition to home delivery.

  1. Go to your Yourstore Dashboard and Go to Settings → Store Settings → Opening Hours
  2. Select Availability days and time that your store operates for customers to pick up the items.
  3. Delay by days and hours are the time required by the store to prepare the order for pickup.
  4. Slot duration is the time interval between each slot, value is to be entered in minutes.
    Example: The input value is 60, the slots will be 10:00 AM - 11:00 AM, 11:00 AM - 12:00 PM.
  5. Delay by hours would allow the customer to select a time slot only after the set duration.
    Example: Let's assume the customer is placing an order by 12:00 PM, delay by hours is set at 3, the customer will be able to select the slot 3:00 PM to 4:00 PM.
  6. Delay by days would allow the customer to select a day and time slot only after the set duration.
    Example: Let's assume the customer is placing an order on Monday, delay by day is set at 3, the customer will be able to select a slot only on Thursday.
  7. Then go to My Account → Branches click on “Add Branch” to create a branch for your store to be displayed for the customer to select during checkout. If your store has more than one branche you can add multiple branches.

Mail Configuration

  1. Go to your Yourstore Dashboard and Go to Settings → Store Settings → Mail Configuration
  2. By default Yourstore sends email to your customers under your store name without you needing to configure anything.
  3. You can choose to update the Fields such as From Name, Contact number & email, these are some information that would be displayed on the email to your customer.
  4. You can add multiple email id’s to the field CC Mails to be alerted to in case a new order comes in or there is any update on the status of the order.
  5. You can add multiple email ids under Billing Mail to which you would like to receive the billing information of your stores like payment reminders and plan expiry.

How to Setup Your Own Email?

If you would like to use your own email, select own Email Checkbox and we support the following email hosts (not available in Yourstore Genie plans) Megamail.io, Gmail, G Suite, EZVeb, Zoho Mail, GoDaddy, Roundcube

Logo Management

You would have probably added your logo to your website while creating your store, if you would like to update your logo you can do it here.

  1. Go to your Yourstore Dashboard and Go to Settings → Store Settings → Logo Management
  2. Click on browse to select and update the new logo.
  3. If you would like to change only a specific logo type you can do it by individually uploading in the list of logos favicon, site logo, social logo and email logo respectively.

Store Management

This module has some necessary controls that help manage your store. (Some options are plan specific)

Guest Checkout
Enabling this option will allow customers to checkout of the store without creating an account. Guest users data is stored and you can view them under Marketing Tools → Customers → Guest Users

Feedback
Enabling this option will allow your customers to give feedback for your service in their My Account section on your website. You can view any feedbacks received Marketing Tools → Feedback

Product Addons
Enabling this option will allow the customer to choose Add Ons or customise their product if you have set it up under Products → Product Extras → Addons

Hide Currency Type
Enabling this option will hide the currency information displayed on the header of your website to the customers.

Shipping only in Domestic
Enabling this option will allow customers only from the same country as the store to place the orders.

Disable Order Delivery
Enabling this option will disable the store from allowing the customers to place orders for delivery.

Display Stock Left
Enabling this option will show the customers the stock available in the product page. You can update value in the minimum stock, in this case only after the stock reaches that limit the customers will be able to see the stock count. Example: If you have entered 3 in minimum stock, only if your inventory count goes below 3 for a product the customer can see the stock count.

Cancel Order Email
You can input the email id to which the cancellation order request alerts get delivered to you.

Minimum Checkout Value
If you would like to set a minimum value the customer should purchase in order to checkout can be set here. If you do not want to restrict the customer, you can leave the value at 0

Gift Wrapping Charges
If you have enabled the gift order option at checkout settings you can set charges if your customer opt for gift wrapping at checkout.

Image Tag Position
If you have created tags for your image like sold out, new arrival, trending, etc.. under Products → Product Extras → Image Tags you can set the position these tags would appear over your product image.

Checkout Setting

Apply Coupon
Enabling this option will allow customers to enter a coupon/offer code at checkout.

Apply Gift Card
Enabling this option will allow customers to enter gift card code at checkout.

Gift Order
Enabling this option will allow customer to mark an order as gift so the store can do the necessary.

Order Notes
Enabling this option will allow customers to enter any special requests during checkout.

Offer except discounted products
If this option is enabled, the coupon/offer code will apply on non-discounted products.

Invoice Setting

Prefix
A letter/number or group of letters/numbers that you put before your invoice number
Example: YS/
Sample Invoice Number: YS/0001

Upcoming Invoice Number
The number form which the invoice series should start
Example:7
Sample Invoice Number: YS/7

Suffix
A letter/number or group of letters/numbers that you put after your invoice number
Example: /22-23
Sample Invoice Number: YS/7/22-23

Min digit
Number of digits the invoice number should have
Example: 4
Sample Invoice Number: YS/0007/22-23

Auto SKU

If you do not maintain your own SKU for your items at stock, you can enable this option to auto generate SKUs

Prefix
A letter or group of letters that you put before your SKU number.
Example: YS

Min Digit
Number of digits the SKU number should have
Example: 4
Sample SKU Number: YS0001
